## 1. Суулгах

### 1.1 Windows

1. [Releases хуудас](https://github.com/sergei10a-rgb/darhai/releases/latest) руу орж өөрийн архитектурт тохирох `.exe` суулгагчийг (x64 эсвэл ARM64) татна.
2. Татсан файлаа ажиллуулна.
3. **Windows SmartScreen-ийн анхааруулга гарвал** — энэ нь хэвийн үзэгдэл. Дархайн суулгагч одоогоор код-гарын үсэггүй (unsigned) тул Windows «Windows protected your PC» гэсэн цэнхэр цонх харуулж болно. Үргэлжлүүлэхийн тулд:
   1. Цонхон дээрх **«More info»** (Дэлгэрэнгүй мэдээлэл) холбоос дээр дарна.
   2. Гарч ирэх **«Run anyway»** (Ямар ч байсан ажиллуулах) товчийг дарна.

   Энэ анхааруулга нь файл вирустай гэсэн үг биш — зөвхөн суулгагч Microsoft-д бүртгэлтэй гарын үсгээр баталгаажаагүйг илтгэнэ. Гарын үсэгтэй build гаргах ажил [Замын зурагт](../ROADMAP.md) тусгагдсан. Суулгагчийг зөвхөн албан ёсны Releases хуудаснаас татаж байгаа эсэхээ үргэлж шалгаарай.
4. Суулгац дуусмагц Дархай нээгдэж, эхний тохиргооны дэлгэц угтана.

### 1.2 macOS ба Linux

- **macOS**: Releases хуудаснаас `.dmg` (Apple Silicon эсвэл Intel) татаж, аппыг Applications хавтас руу чирнэ.
- **Linux (Debian/Ubuntu)**: `.deb` багц татаж `sudo dpkg -i <файл>.deb` командаар суулгана.
- **WSL2 дээр ажиллуулах гэж байгаа бол**: Electron-ы гацалт болон AVX-гүй CPU-ийн асуудлыг тойрох тусгай заавар бий — [WSL2 Workaround](wsl2-workaround.md).
- **Headless сервер дээр байршуулах бол**: [Сервер байршуулалтын заавар](deploy-server.md).

Суулгагч нь Darhai-Core хөдөлгүүрийг багтаасан тул нэмэлт runtime (Node, Python) суулгах шаардлагагүй.

## 2. Эхний тохиргоо (onboarding)

Аппыг анх нээхэд «**Дархайд тавтай морил**» урсгал таныг дагуулна:

1. **Нэрээ оруулах** — Дархай таныг хэн гэж дуудахаа мэднэ. Google бүртгэлээрээ үргэлжлүүлбэл Gemini-ийн үнэгүй суурь хязгаартай шууд эхэлж болно.
2. **Автомат илрүүлэлт** — Дархай таны машин дээр аль хэдийн суусан хэрэгсэл, түлхүүрүүдийг локал орчинд хайна: PATH дээрх CLI-ууд, орчны хувьсагч дахь API түлхүүрүүд, Ollama-ийн дотоод загварууд. Юу ч таны төхөөрөмжөөс гарахгүй. Олдсон бүхэн автоматаар холбогдоно.
3. **Орох замаа сонгох** — дараах сонголтуудын аль нэгийг (эсвэл хэд хэдийг) хийнэ:
   - **Нийлүүлэгчийн түлхүүр буулгах** — Anthropic, OpenAI, Google, DeepSeek, Moonshot зэрэг нийлүүлэгчийн API түлхүүрийг буулгахад ухаалаг таних систем аль нийлүүлэгчийнх болохыг өөрөө тодорхойлно.
   - **Google-аар нэвтрэх** — Google бүртгэлээрээ Gemini-г үнэгүй ашиглаж эхлэх.
   - **Ollama** — таны машин дээрх дотоод загварууд; юу ч төхөөрөмжөөс гарахыг хүсэхгүй бол хамгийн тохиромжтой (16 ГБ видео RAM-аас дээш зөвлөмжтэй).
   - **Flux Router холбох** — хүсэлт бүрийг тохирох загвар руу автоматаар чиглүүлдэг гуравдагч талын нэмэлт үйлчилгээ. Заавал биш.
4. **Сонирхлоо сонгох** — таны ажлын чиглэлд (контент, борлуулалт, хөгжүүлэлт, санхүү г.м.) тохирох туслах, хэрэгсэл, товчлолуудыг урьдчилан ачаална.

Эдгээрийн аль нь ч таныг түгжихгүй: илрүүлэлт нэг удаа ажиллах бөгөөд дараа нь бүгдийг **Тохиргоо** хэсэгт өөрчилж болно. Аль ч алхмыг «Одоохондоо алгасах» гэж алгасаж болно.

## 3. AI CLI агентуудыг холбох

Дархай CLI бүрийг [ACP](https://agentclientprotocol.com) горимд эхлүүлдэг бөгөөд **CLI-ийн өөрийн нэвтрэлтийг** ашиглана — тусдаа бүртгэл шаардлагагүй.

| Агент | Юу хэрэгтэй |
|:--|:--|
| **Claude Code** | Терминалд `claude` командаар нэвтэрсэн байх, эсвэл `ANTHROPIC_API_KEY` |
| **Codex** (OpenAI) | ChatGPT нэвтрэлт эсвэл `OPENAI_API_KEY` |
| **Gemini** (Google) | Апп доторх Google нэвтрэлт (шууд дэмжлэгтэй) |
| **Qwen Code, Goose, OpenCode, Kimi** г.м. | Тухайн CLI-ийн нэвтрэлт эсвэл нийлүүлэгчийн түлхүүр |

Хэрэв аль нэг агент «**энд нэвтэрч чадахгүй**» гэсэн мэдэгдэл харуулбал Дархай гурван гарцыг санал болгоно:

1. **Нийлүүлэгчийн API түлхүүр нэмэх** — Тохиргоог нээж нийлүүлэгчийн консолоос түлхүүр буулгах;
2. **CLI рүү нэвтрэх** — заасан командыг (жишээ нь `claude` эсвэл `codex login`) терминал дээрээ ажиллуулаад зурвасаа дахин илгээх;
3. **Flux Router-ээр чиглүүлэх** (сонголтоор).

Түлхүүрүүд үйлдлийн системийн keychain-д хадгалагдана; Дархай тэдгээрийг хэзээ ч гадагш илгээхгүй.

## 4. Үндсэн ажиллагаа: чат

### 4.1 Чат эхлүүлэх

- Нүүр дэлгэцийн «**Сайн уу, өнөөдөр та юу хийх төлөвлөгөөтэй вэ?**» талбарт зурвасаа бичээд **Илгээх** дарна, эсвэл хажуугийн самбараас **Шинэ чат** сонгоно.
- **Командын самбар** (Ctrl/Cmd+K)-аар туслах, чат, эхлэх промптуудыг хурдан хайж нээнэ.
- Чатын түүх хажуугийн самбарын **Сүүлийн чатууд** хэсэгт хадгалагдана: нэр өөрчлөх, бэхлэх, багцаар экспортлох (JSON + Markdown + ажлын талбарын файлууд ZIP-ээр), устгах боломжтой.

### 4.2 Агент ба загвар сонгох

- Оролтын талбарын дэргэдэх сонголтоос **CLI агентууд** (Claude Code, Codex, Gemini…) эсвэл **урьдчилан тохируулсан туслахуудаас** сонгоно.
- **Загвар сонгох** цэснээс тухайн агентын боломжит загваруудыг харна. Загваруудын жагсаалт анхны холболтын дараа ачаалагдана — эхний зурвасаа илгээснээр идэвхжинэ.
- Ажлын дундуур загвар, агент солиход яриа тасрахгүй; загварын квот дуусвал Дархай өөр загвар руу шилжихийг санал болгоно.

### 4.3 Файл, хавтастай ажиллах

- **Файл байршуулах** — зурвастаа файл хавсаргана (чирж буулгаж болно).
- **Хавтас нээх** — чатыг тодорхой хавтсанд «суулгана»: энэ нь тухайн чатын **Ажлын талбар** болж, агент доторх файлуудыг уншиж, засаж чадна.
- Ажлын талбарын самбараас файлуудыг үзэх, урьдчилан харах, нэр өөрчлөх, VS Code / Терминал / Файл хөтчөөр нээх боломжтой.
- **Өөрчлөлтүүд** таб нь AI-ийн хийсэн файлын өөрчлөлтүүдийг (git diff маягаар) харуулж, бэлтгэх/буцаах удирдлага өгнө.

### 4.4 Бусад чадварууд

- **Хажуугийн асуулт** (`/btw`) — үндсэн даалгаврыг тасалдуулалгүйгээр одоогийн ярианы агуулгаас богино асуулт асууна.
- **Дараалалд орсон командууд** — агент ажиллаж байх зуур дараагийн командуудаа дараалалд нэмж, засаж, эрэмбэлж болно.
- **Дуу хоолойны оролт** — микрофоноор ярьж зурвас бичүүлэх (яриаг текст болгох тохиргоо шаардана).
- **Олон агентын горим** — нэг ажилд хэд хэдэн агентыг зэрэг дайчлах.

## 5. Төслүүд ба мэдлэгийн сан

**Төслүүд** нь холбоотой чатуудыг нэг дор бүлэглэж, дундын контексттэй болгоно.

1. Хажуугийн самбараас **Төслүүд → Шинэ төсөл** сонгоно.
2. Нэр, тайлбар, (сонголтоор) **ажлын талбарын хавтас** зааж өгнө — энэ төслийн чатууд эндээс эхэлж, хавтсанд мэдлэгийн сан үүснэ.
3. Төслийн цонх дараах табуудтай:
   - **Чатууд** — төслийн бүх яриа; аль ч backend, загвар, туслахаар шинэ чат нээж болно, хэд хэдийг зэрэг ажиллуулж болно.
   - **Файлууд** — төслийн ажлын талбар.
   - **Мэдлэг** — бүх чаттай хуваалцагдах **Заавар**, **Дүрэм ба зарчмууд**, **Шийдвэрүүд**. «Зааврын шидтэн» хэдэн асуултад хариулснаар ноорог гаргаж өгнө.
   - **Лавлагаа** — AI-ийн ашиглах материал: PDF, Markdown, CSV, зураг…
   - **Санах ой** — энэ төсөлд гаргасан шийдвэр, сургамжууд; бүх чатад дамжих тул нэг зүйл дахин маргагдахгүй.

Чатыг төсөлд нэмэх/хасахад чат өөрөө устахгүй — зөвхөн бүлэглэлт өөрчлөгдөнө.

## 6. Туслахууд ба Багууд

### 6.1 Туслахууд

**Туслахууд** хуудсанд суурь туслахууд, мэргэжилтнүүд жагсана. Туслах бүр өөрийн дүрэм (промпт), боломжит загварууд, ур чадварын багцтай.

- **Өөрийгөө бүтээх** — хоосон туслахаас эхэлж нэр, аватар, тайлбар, промпт, дүрэм, ур чадваруудыг тохируулна (Тохиргоо → Туслахууд).
- Туслахыг хувилах, идэвхжүүлэх/идэвхгүй болгох, аль agent backend дээр ажиллахыг нь солих боломжтой.

### 6.2 Багууд

**Багууд** нь ахлагчтай, гишүүдтэй AI мэргэжилтнүүдийн бүрэлдэхүүн:

1. **Багууд → Өөрийн баг бүтээх** (эсвэл бэлэн багаас сонгох).
2. **Багийн ахлагч** сонгож, **гишүүд** (мэргэжилтнүүд) нэмнэ; үүрэг тус бүрд backend сонгоно.
3. Эсвэл зорилгоо энгийн хэлээр бичээд «**Санал болгох**» дарвал Дархай бүрэлдэхүүнийг өөрөө санал болгоно.
4. **Баг эхлүүлэх** — баг нэг хуваалцсан самбар дээр ажил дуустал бие даан ажиллана. Явцыг **Үйл ажиллагаа** таб болон Удирдлагын төвөөс хянана.

Тогтмол ажиллуулах багаа **Байнгын компани** болгон дэвшүүлбэл сешн хооронд хадгалагдаж, тогтсон зан үйлүүдтэй (rituals) ажиллана. Гаднаас баг импортлохдоо түүний зарласан боломжуудыг (файл унших/бичих, гишүүн үүсгэх, сүлжээний хандалт…) хянаж, зөвхөн итгэсэн зүйлдээ зөвшөөрөл олгоно.

## 7. Ур чадварууд

**Ур чадвар** гэдэг нь агентад тодорхой ажлыг мэргэжлийн түвшинд хийх зааварчилгаа өгдөг багц (SKILL.md формат).

- **Ур чадварууд** хуудас: Дархай сангийн 2,000+ ур чадвар, таны өөрийн болон импортолсон ур чадварууд, ангилал/эх сурвалж/төлөвөөр шүүлт.
- **Импортлох** — хавтас, Git URL, ZIP файл, эсвэл ганц SKILL.md файлаас. Импортын үед аюулгүй байдлын скан ажиллаж, үр дүнг **Цэвэр / Хяналт шаардлагатай / Хаагдсан** гэж ангилна.
- **Ур чадвар бүтээх** — өөрөө бичих эсвэл юу хийхийг нь тайлбарлаад AI-аар үүсгүүлэх.
- **CLI илрүүлэлт** — `~/.claude/skills`, `~/.codex/skills`, `~/.gemini/skills` дахь ур чадваруудыг Дархайд тусгана (дахин эхлүүлэлт шаардана).
- **Тохиргоо → Ур чадварын төв** — ур чадваруудыг төвлөрсөн байдлаар удирдаж, аль ч туслахад идэвхжүүлнэ; чухал ур чадварыг бүх туслахад **бэхлэж** болно.

## 8. Санах ой

**Санах ой** хуудас (хажуугийн самбар) нь суурин санах ойн хөдөлгүүрээр ажиллана:

- Анх орохдоо «**Санах ой суулгах**» товчоор нэг удаагийн суулгац хийнэ (npm шаардана, ойролцоогоор нэг минут).
- Санах ой чат, төсөл, CLI-уудын хооронд тогтвортой хадгалагдаж, туслах бүр контекстээ автоматаар авна.
- **Хайх** таб — «Бид ямар нэвтрэлтийн стек дээр тогтсон бэ?» гэх мэт асуултаар өөрийн санах ойгоос хайна.
- **Вики** — давтагдсан санах ойнуудаас нэгтгэгдсэн ойлголтын хуудсууд; бэлэн болсон бичлэгүүдийг **Дэвшүүлэх** товчоор Вики рүү оруулна.
- Гадны CLI-ууд (Claude Code, Codex, Gemini CLI) мөн энэ санах ойг хуваалцана.
- Хүсэхгүй бол Тохиргооноос идэвхгүй болгож болно; өгөгдөл бүхэлдээ таны диск дээр үлдэнэ.

## 9. MCP серверүүд

**MCP интеграц** хуудсаар Model Context Protocol серверүүдийг удирдана:

1. **Сервер нэмэх** — stdio, SSE, эсвэл streamable-HTTP дамжуулалтаар дурын MCP сервер холбоно.
2. **Серверүүд** таб — холболтын төлөв (Холбогдсон / Салгагдсан / Алдаа), сүүлийн шалгалт, боломжууд.
3. **Хэрэгслүүд** таб — сервер бүрийн өгч буй хэрэгслүүд; гараар турших, параметртэй нь **Гүйцэтгэх** боломжтой.
4. **Гүйцэтгэлийн түүх** — хэрэгслийн дуудлага бүрийн бүртгэл. Агент MCP хэрэгсэл ашиглах үед та **Зөвшөөрөх / Татгалзах** сонголттой.

MCP хөгжүүлэлт, дебаг хийхэд [CDP заавар](cdp.md)-ыг үзнэ үү.

## 10. Сувгууд

**Тохиргоо → Сувгууд** хэсгээр Дархайтай апп-аас гадуур харилцах сувгуудыг холбоно. Суваг бүр өөрийн тохиргооны маягттай:

- **Telegram** — @BotFather-ээр бот үүсгэж холбоно; ботдоо бичихэд Дархай тэндээ хариулна.
- **Slack** — Socket Mode (нийтийн URL шаардахгүй) эсвэл Events API-ээр бот нэгтгэл.
- **Discord** — Developer Portal-д бот үүсгэж, токеноор холбоно.
- **WhatsApp** — QR холболт (Baileys), WhatsApp Web.js, эсвэл Meta Business Cloud API.
- **Signal, Matrix, MS Teams, LINE, Twitch, Google Chat, DingTalk, Lark, WeChat, WeCom, SMS (Twilio)** — тус бүрийн маягтад нэвтрэх мэдээллээ оруулж «**Шалгаж идэвхжүүлэх**» дарна.

Сувгууд үе шаттайгаар нэмэгдэж байгаа тул зарим нь «удахгүй ирнэ» төлөвтэй байж болно — тухайн сувгийн картан дээрх төлөвийг харна уу. Холболт амжилттай болмогц Дархай тухайн сувгаар мэндчилгээ илгээнэ; та хэдийд ч хариулж, ажлаа үргэлжлүүлж болно.

## 11. Ажлын урсгал, хуваарьт даалгавар, Удирдлагын төв

- **Ажлын урсгал** — нэг товшилтоор эхлүүлэх, алхам алхмаар дагуулах бэлэн жорууд (эхлүүлэх төлөвлөгөө, өрсөлдөгчийн задаргаа, сарын контент…). Урсгалаа сонгож, хөдөлгүүрээ (агентаа) сонгоход л болно.
- **Хуваарьт даалгаврууд** — аль ч чатыг хуваарьт тавьж (чатын цэснээс «Энэ чатыг хуваарьт оруулах»), өдөр/долоо хоног/сар бүр автоматаар ажиллуулна. Даалгавар бүр үр дүнгээ өөрийн яриандаа хүргэнэ; дараагийн болон сүүлийн ажиллалтыг харж, түр зогсоож болно.
- **Удирдлагын төв** — багуудын бүх даалгавар, хуваарьт ажил нэг амьд самбарт: юу ажиллаж байна, юу хүлээгдэж байна, юу амжилтгүй болсныг шууд харна.

## 12. Алсын хандалт (WebUI)

**Тохиргоо → Алсын** хэсгээс Дархайг хөтчөөр хандах боломжтой болгоно:

1. **WebUI идэвхжүүлэх** — суулгасан веб үйлчилгээ эхэлнэ (порт тохируулж болно).
2. **Алсын хандалт зөвшөөрөх** — дотоод сүлжээний бусад төхөөрөмжөөс хандахыг нээнэ.
3. **Хандах URL-ууд** хэсгээс локал/сүлжээний URL-ийг хуулах, эсвэл **QR кодоор нэвтрэх** — утасныхаа камераар уншуулахад хөтөч дээр автоматаар нэвтэрнэ.
4. Хэрэглэгчийн нэр, нууц үгийг мөн эндээс солино (анхны нууц үгийг үүсгэсний дараа заавал солихыг зөвлөнө).

Дэлгэрэнгүй: [WebUI-ийн заавар](webui.md) (Windows/macOS/Linux/Termux дээр эхлүүлэх), сервер дээр байршуулах бол [Headless сервер байршуулалт](deploy-server.md).

## 13. Тохиргоо

**Тохиргоо** (хажуугийн самбар эсвэл tray) нь **AI цөм**, **Програм**, **Бусад** бүлэгтэй. Түгээмэл хэрэглэгддэг хэсгүүд:

| Тохиргоо | Юу хийдэг |
|---|---|
| **Хэл** | Интерфэйсийн хэлийг солино — Монгол (анхдагч) эсвэл English. |
| **Загвар** | Загварын платформ нэмэх/засах: нийлүүлэгч, үндсэн URL, API түлхүүр(үүд). Олон түлхүүр оруулбал автоматаар ээлжлэн ашиглана. |
| **Туслахууд / Агентууд** | Туслах бүтээх, засах, ур чадвар оноох. |
| **Чадварууд** | Ур чадварууд болон «MCP ба дуу хоолой» табууд. |
| **Сувгууд** | Мессежийн сувгуудын холболт (§10). |
| **Алсын** | WebUI ба алсын хандалт (§12). |
| **Автопилот** | Зөвшөөрлийн шалгалтуудыг автоматаар зөвшөөрөх горим. Болгоомжтой хэрэглээрэй — агент асуулгүйгээр үйлдэл хийнэ. |
| **Загвар (харагдац)** | Цайвар/Бараан горим, UI томруулалт, хөдөлгөөн багасгах, тусгай CSS. |
| **Систем** | Ачаалахад эхлүүлэх, tray руу хаах, мэдэгдэл, шинэчлэлтийн горим, кэш/ажлын/логийн хавтас. |

**Үндсэн дүрэм**: `~/.darhai/CONSTITUTION.md` файлд энгийн хэлээр бичсэн дүрмүүд тань аль ч CLI ажил гүйцэтгэснээс үл хамааран бүх агентын эргэлт бүрд нэмэгдэнэ (кодын стандарт, өнгө аяс, хориглосон зүйлс…).

## 14. Шинэчлэлт

Дархай шинэчлэлтээ [GitHub Releases](https://github.com/sergei10a-rgb/darhai/releases)-ээс авдаг:

- Апп ачаалахад цаана шинэчлэлт шалгана; tray цэсний «**Шинэчлэлт шалгах**»-аар гараар шалгаж болно.
- Шинэ хувилбар олдвол «**Программ хангамжийн шинэчлэл**» цонх хувилбарын тэмдэглэлийн хамт гарна: **Татаж суулгах** → татагдсаны дараа **Суулгаж дахин эхлүүлэх**.
- Татсан шинэчлэл бүр гарын үсэгтэй мета өгөгдөл (`latest.yml`) болон checksum-аар баталгаажина; шалгалтад тэнцээгүй файлыг Дархай ажиллуулахаас татгалзана.
- **Авто шинэчлэлийн горим**-ыг Тохиргоо → Систем хэсгээс удирдана.

|---|---|
| **Windows суулгагч нээгдэхгүй, SmartScreen хориглож байна** | §1.1-ийг үзнэ: «More info» → «Run anyway». Файлыг зөвхөн албан ёсны Releases хуудаснаас татсан эсэхээ шалгана. |

| **«Загвар тохируулаагүй байна»** | Тохиргоо → Загвар хэсэгт дор хаяж нэг нийлүүлэгч, түлхүүр нэмнэ. |
| **Загварын квот дууссан** | Гарч ирэх сонголтоор өөр загвар руу шилжих, эсвэл өөр нийлүүлэгчийн түлхүүр нэмэх. |
| **Санах ой суулгагдахгүй** | `npm` таны PATH дээр байгаа эсэхийг шалгана; гараар суулгах бол терминалд `npx -y @ijfw/install@latest`. |
| **WebUI-д алсаас хандаж чадахгүй** | «Алсын хандалт зөвшөөрөх» асаалттай эсэх, firewall порт нээлттэй эсэхийг шалгана — [WebUI заавар](webui.md)-ын Troubleshooting хэсэг. |
| **Шинэчлэлт «checksum зөрчилдсөн» гэж унав** | Татсан файл гэмтсэн — дахин оролдох эсвэл Releases хуудаснаас гараар татна. |
| **Лог хэрэгтэй (алдаа мэдээлэх)** | Тохиргоо → Систем хэсэгт **Логийн хавтас** зам бий — тэндхийн сүүлийн лог файлуудыг [GitHub Issues](https://github.com/sergei10a-rgb/darhai/issues)-т хавсаргана. |
| **MCP/гүнзгий дебаг** | [CDP заавар](cdp.md): Тохиргоо → Систем → Хөгжүүлэгчийн дебаг → CDP идэвхжүүлэх. |
