## Замдаа олсон гуравдагч алдаа

`ErrorBoundary.tsx` нь `electron-log/renderer`-ийг **модулийн түвшинд** импортолдог байв. Тэр багц
renderer орчин шаарддаг тул node орчинд импорт хийхэд процесс унана. Preview-ийн харагчдыг тэр
boundary-д ороосон даруйд node тестийн worker хатуу унаж, vitest хариу ирэхгүй fork-ыг мөнхөд
хүлээж эхэлсэн — иж бүрдэл **40 сек → хэзээ ч дуусахгүй** болов.

Зөвхөн уналтын дараа ажилладаг логийн мөр нь тухайн компонентыг хаанаас импортлож болохыг
шийдэж болохгүй. Логгерыг `componentDidCatch` дотор л ачаалдаг болгов; логгер олдохгүй бол
`console.error` рүү шилжинэ — fallback UI ямар ч тохиолдолд гарна.

**Оношлох арга (дараагийн удаад):** `timeout N`-тэй ажиллуулахад vitest-ийн «Duration» яг N
болж байвал тестүүд дуусаад **процесс гарахгүй** байна гэсэн үг — гацсан тест биш. `Test Files`-ийн
тоо цэвэр суурьтай харьцуулахад **нэгээр дутуу** байвал тэр нь унасан worker.
