## Автомат сешний ажиллах дүрэм

1. **Эхлээд унш:** энэ файл → холбогдох `tierN-progress.md`. Санах ойд бүү найд.
2. **Нэг зүйл ав.** Дараалалаас дараагийн нэгийг. Олныг зэрэг бүү эхлүүл.
3. **Порт хийхээс өмнө ШАЛГА.** Tier 1-д 10-аас 4 нь, Tier 0-д 1-ээс 1 нь
   Дархайд аль хэдийн илүү сайн хийгдсэн байсан. Тайлан fork цэг (2026-06-21)
   дээр суурилсан, түүнээс хойш Дархай 221 commit явсан.
4. **Тест + мутаци заавал.** Засвар бүр RED → GREEN → mutation proof.
5. **UI өөрчилсөн бол зургаар нүдээр хар.** 2026-08-21-нд гурван согог зөвхөн
   зургаар олдсон, 14,000 тест ногоон байхад.
6. **Дуусмагц энэ файл + `tierN-progress.md`-г шинэчил.** Тэмдэглээгүй ажил
   дараагийн сешнд давхардана.
7. **Дуусаагүй бол push БҮҮ хий.** Хагас ажил push хийвэл дараагийн сешн
   эвдэрсэн модон дээр эхэлнэ. Дуусаагүй бол ажлын талбарт үлдээж, энэ файлд
   «явцтай: <юу>» гэж бич.
