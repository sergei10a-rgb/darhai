# Дархай — Замын зураг (Roadmap)

**Статус:** идэвхтэй чиглэл · одоогийн хувилбар `v0.9.6-rc.2.1` · репо [sergei10a-rgb/darhai](https://github.com/sergei10a-rgb/darhai)

> ⚠️ **Энэ бол чиглэл, амлалт биш.** Доорх зүйлс нь Дархайн хөгжлийн зорьж буй дарааллыг харуулна. Огноо, эцсийн хугацаа байхгүй — ажил бүр чанарын шалгуураа хангасан үедээ л гарна. Дараалал болон агуулга өөрчлөгдөж болно.

---

## Гарал үүсэл: upstream Wayland

Дархай нь Ferrox Labs-ын нээлттэй эхийн **Wayland** дэсктоп аппаас салбарласан (fork). Wayland-ын өөрийн замын зураг — сувгуудын өргөтгөл, Gemini A2A шилжилт, багийн сан, sync, extension marketplace гэх мэт — upstream репод хөгжсөөр байгаа бөгөөд Дархай тэдгээр ажлын үр шимийг тогтмол нэгтгэлтээр (merge) хүртэнэ.

Энэ баримт нь **Дархайн өөрийн**, upstream-аас гадуурх ажлыг л тодорхойлно. Upstream-д аль хэдийн төлөвлөгдсөн зүйлийг энд давхардуулахгүй.

## Чиглэл А — 1.0 тогтвортой Монгол хувилбар

**Зорилго:** Дархайг «ажилладаг fork»-оос «Монголын хэрэглэгчдэд итгэлтэй санал болгож болох бүтээгдэхүүн» болгох.

### Хамрах хүрээ

- **Орчуулгын бүрэн байдал.** `mn-MN` локалын бүх модулийг (тохиргоо, сувгууд, onboarding, санах ой, багууд…) бүрэн, нэгдсэн нэр томьёотой болгож дуусгах; `node scripts/check-i18n.js` шалгалтыг CI-д тогтмолжуулах; интерфэйс дээр үлдсэн англи үг үсгийн үлдэгдлийг цэвэрлэх.
- **Баримтжуулалт монголоор.** [Танилцуулга](introduction.md) ба [Хэрэглэгчийн гарын авлага](guides/user-manual.md)-ыг апп өөрчлөгдөх бүрд шинэчилж хэвших.
- **Unsigned → signed build.** Одоогийн Windows суулгагч гарын үсэггүй тул SmartScreen анхааруулга гардаг. Код-гарын үсгийн гэрчилгээ авч electron-builder-т холбох; macOS-д notarization-ыг мөн судлах. (Гэрчилгээний зардал, худалдан авалт нь инженерийн бус, үйл ажиллагааны шийдвэр.)
- **Release автоматжуулалт.** Tag → build (Windows/macOS/Linux) → GitHub Releases артефакт → авто-шинэчлэлтийн мета өгөгдөл (`latest.yml`) хүртэлх гинжийг CI-д бүрэн автоматжуулж, гараар багцлахыг зогсоох.
- **Release smoke.** Хувилбар бүрд: суулгагч нээгдэж, onboarding дуусаж, дор хаяж нэг CLI агентаар чат ажиллаж, авто-шинэчлэлт өмнөх хувилбараас амжилттай шилждэг байх.

### Дуусах шалгуур

- Аппын аль ч дэлгэц дээр орчуулгагүй мөр харагдахгүй.
- Releases хуудсанд гурван платформын артефакт CI-ээс автоматаар гарсан байна.
- Windows суулгагч SmartScreen-ийн «Unknown publisher» анхааруулгагүй суудаг болсон байна (гэрчилгээ авагдсан тохиолдолд).

## Чиглэл Б — Монгол экосистем

**Зорилго:** Дархайг зөвхөн «монгол интерфэйстэй» биш, **монгол хэлээр ажилладаг** агент болгох.

### Хамрах хүрээ

- **Монгол STT интеграц.** Дархайн дуу хоолойны оролтыг монгол хэлний speech-to-text үйлчилгээтэй холбох боломж — тохиргоонд өөрийн STT endpoint зааж өгөх хэлбэрээр. Локал буюу өөрөө хостолсон STT-г түрүүнд тавина.
- **Монгол TTS.** Агентын хариуг монголоор уншуулах гаралтын суваг — мөн залгаж болдог, солигддог үйлчилгээ хэлбэрээр.
- **Локал загварууд.** Ollama-гаар дамжуулан монгол хэл дээр боломжийн ажилладаг нээлттэй загваруудыг туршиж, зөвлөмж болгон баримтжуулах; бүрэн офлайн (сүлжээгүй) ажиллагааны монгол хэрэглээний жишиг тохиргоог гаргах.
- **Монгол контент.** Ажлын урсгал, туслахуудын монгол хэл дээрх багц — Монголын бизнесийн нийтлэг хэрэглээнд (тайлан, гэрээ, албан бичиг…) тохирсон жорууд.

### Дуусах шалгуур

- Хэрэглэгч микрофоноор монголоор ярьж даалгавар өгч, хариугаа монголоор сонсож чаддаг байх (тохируулсан STT/TTS-тэй үед).
- «Интернэтгүй, бүх юм дотооддоо» гэсэн байгууллагын хэрэглээний баримтжуулсан жишиг тохиргоо бэлэн байх.

## Чиглэл В — Upstream sync стратеги

**Зорилго:** Дархай upstream Wayland-ын хөгжлөөс хоцрохгүй, гэхдээ монгол давхаргаа алдахгүй байх.

### Ажиллах зарчим

- **Тогтмол merge.** `FerroxLabs/wayland`-ын тогтвортой tag-уудыг тодорхой давтамжтайгаар Дархай руу нэгтгэнэ. Merge бүр тусдаа салбар дээр хийгдэж, тест (`bun run test`, `bun run lint`, `tsc`) ногоон болсны дараа л main-д орно.
- **Монгол давхаргыг хамгаалах.** Fork-ын өөрийн өөрчлөлтүүд (mn-MN локал, брэнд asset-ууд, монгол баримтжуулалт, анхдагч хэлний тохиргоо) нь боломжит хэмжээнд тусгаарлагдсан файлуудад амьдарч, merge conflict-ын гадаргууг багасгана.
- **i18n шинэ түлхүүрүүд.** Upstream шинэ UI мөр нэмэх бүрд `mn-MN`-д тухайн түлхүүрүүдийг орчуулах ажил sync-ийн заавал нэг хэсэг байна — орчуулагдаагүй мөртэй release гаргахгүй.
- **Сонгомол нэгтгэл.** Upstream-ын бүх боломж Монголын зах зээлд шууд хамаатай биш байж болно; feature бүрийг «авна / хойшлуулна / хасна» гэж ухамсартай шийднэ. Шийдвэрүүдийг энэ баримтын төгсгөлийн «Шийдсэн» бүртгэлд тэмдэглэнэ.

### Дуусах шалгуур (sync бүрд)

- Тест, lint, typecheck ногоон.
- `node scripts/check-i18n.js` алдаагүй — шинэ түлхүүр бүр монгол орчуулгатай.
- Fork-ын брэнд, лиценз, баримтжуулалтын өөрчлөлтүүд гэмтээгүй.

---

## Хамрахгүй зүйлс

- **Upstream-ын өөрийн замын зураг.** Wayland-ын сувгуудын өргөтгөл, engine-ийн хөгжил гэх мэт нь upstream-д төлөвлөгддөг; Дархай тэдгээрийг sync-ээр авахаас биш өөрөө давхар хөгжүүлэхгүй.
- **Огноотой амлалтууд.** Энэ баримтад зориуд ямар ч хугацаа байхгүй.
- **Тусдаа арилжааны үйлчилгээний архитектур.** Дархай дээр суурилсан үйлчилгээний загвар нь энэ репогийн бус, бизнесийн түвшний асуудал.
