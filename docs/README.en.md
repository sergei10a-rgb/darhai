# Darhai documentation

English | [Монгол](README.md)

Documentation is organized by the reader's goal, not by document type.

| Directory                       | Who it is for         | What it holds                                                                                                |
| ------------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------ |
| [`guides/`](guides)             | Users, operators      | How to use, deploy, and test the product: user manual, server deployment, WebUI, Hub testing, CDP debugging. |
| [`contributing/`](contributing) | Contributors          | Development environment setup, file-structure rules, PR automation flow.                                     |
| [`architecture/`](architecture) | Engineers, architects | System architecture overview, subsystem breakdowns (ACP, queue, team mode), and research notes.              |
| [`legal/`](legal)               | Every reader          | Third-party licenses and attribution notices.                                                                |
